## 💻 Run Locally

1. Clone this repository:

```bash
git clone https://github.com/jash1210/ctf-writeups.git
```

2. Navigate into the project:

```bash
cd ctf-writeups
```

3. Open `index.html` in your browser.

That's it! No dependencies or installation required.

## 🌍 Deployment

This website is hosted for free using GitHub Pages.

To deploy:

1. Open your GitHub repository.
2. Navigate to Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Click Save.

Your website will be published at:

https://jash1210.github.io/ctf-writeups/
